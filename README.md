# Swiggy Business Analytics — CA1 (Set B)

An academic, end-to-end business analytics case study using **Microsoft SQL Server** and **Python (Pandas)** to examine restaurant economics, delivery performance, and operational data quality.

> **Data disclaimer:** The assigned dataset is synthetic and intended only for educational assessment. It does not represent actual Swiggy customers, orders, delivery partners, restaurant performance, or internal company data.

## Project Overview

The case study models the relationships between customers, restaurants, delivery partners, and orders. It uses SQL queries and Python/Pandas analysis to turn the supplied dataset into traceable operational metrics and evidence-based recommendations.

## Tools & Technologies

- Microsoft SQL Server Management Studio (SSMS)
- SQL (relational schema, constraints, joins, aggregations, subqueries)
- Python
- Pandas

## Assessment Coverage

- Relational database design, primary keys, foreign keys, and data constraints
- Delivered-order delivery performance by city
- Restaurant platform commission analysis
- SQL joins, aggregations, filtering, ranking, and subqueries
- Python/Pandas data preparation and quality checks
- Operational feature engineering and evidence-based prioritisation

2. Load the assigned Set B dataset into the database using the table definitions and import steps in the solution.
3. Run the SQL sections in order.
4. Open the Python notebook in Jupyter Notebook or Google Colab.
5. Update any file paths if needed, then run the notebook from top to bottom.
